# X500급 기체 학습 모델 (`v3x500`, 2026-10-15)

학습 과제 `v3x500`의 기체 값을 정리한 문서입니다. 값을 고치실 때는 표의 "값" 칸을 바꿔 보내 주시면 됩니다.

- **기준 기체:** PX4 v1.16 SITL의 Gazebo 기본 기체 `x500`입니다. 실제로 쓰실 X500의 측정값이 있으면 그 값으로 바꿉니다.
- **값을 읽은 파일:** 모두 `erc_gcs:boo-migration` 이미지의 `/root/PX4-Autopilot` 아래에 있습니다.
  - `Tools/simulation/gz/models/x500_base/model.sdf`: 질량, 관성, 로터 위치, 프로펠러 메시
  - `Tools/simulation/gz/models/x500/model.sdf`: 모터 모델 상수
  - `ROMFS/px4fmu_common/init.d-posix/airframes/4001_gz_x500`: 할당 기하, 모터 출력 범위, 정지 비행 추력
  - `build/px4_sitl_default/parameters.json`: `MC_*`, `MPC_*` 기본값
- **계산 스크립트:** `analysis/x500_derive.py`

## 1. 값과 출처

출처 칸의 뜻은 이렇습니다.

- **읽음:** PX4 파일에 적힌 값 그대로입니다.
- **계산:** 읽은 값에서 계산한 값입니다.
- **가정:** 파일에 없어 정한 값입니다. 가장 먼저 확인이 필요합니다.

### 1.2 자세 루프 환산

PX4 기본값(`MC_ROLL_P` 6.5, `MC_ROLLRATE_P` 0.15, `MC_ROLLRATE_D` 0.003; 피치도 같음)을 학습 제어기의 각가속 단위로 바꿨습니다.

- 정규화 토크 1이 실제 각가속 얼마인지는 PX4 할당 정규화(`ControlAllocationPseudoInverse`)와 gz 모터 곡선으로 계산했습니다. 롤은 143, 피치는 230 rad/s²입니다.
- 두 축이 다른 이유는 PX4 할당 기하(0.13 × 0.22 m)가 gz 모델의 실제 기하(0.174 × 0.174 m)와 다르기 때문입니다.
- D 항을 유효 관성으로 넣으면 롤 98 / 15, 피치 133 / 20입니다. D 항을 빼면 롤 139 / 21, 피치 224 / 35입니다.
- 학습 제어기는 축 하나의 값만 받으므로 그 사이 값인 115 / 17.5를 썼습니다.
- 이 범위 안에서는 어느 값을 써도 속도 계단 응답이 63 % 도달 기준 0.02 s, 90 % 도달 기준 0.03 s 안에서 같습니다.

## 2. 확인

- **질량·관성:** Isaac이 읽은 값이 2.064 kg, (0.02384, 0.02394, 0.044)로 넣은 값과 같습니다.
- **계단 응답:** Isaac에서 잰 8종이 계산 모델과 0.01 s 안에서 같습니다(`scripts/x8_body_check.py --task v3x500`, 기록 `analysis/x8_body_check_x500.log`). 평활 없이 잰 범위는 아래와 같습니다.

| 계단 | 63 % 도달 | 90 % 도달 | 최대 기울기 | 넘침 |
|---|---|---|---|---|
| 0 → 3 m/s | 0.47–0.86 s | 0.68–1.32 s | 23–34° | 0.07 m/s |
| 3 → 0 m/s | 0.46–0.86 s | 0.66–1.32 s | 21–33° | 0.07 m/s |
| 90° 전환 | 0.57–0.87 s | 0.81–1.34 s | 30–35° | 0.05 m/s |
| 0 → 5 m/s | 0.65–0.87 s | 0.92–1.33 s | 34–35° | 0.06 m/s |

  - 정지 거리는 1 / 3 / 5 m/s에서 0.35–0.82 / 1.19–2.46 / 2.63–4.11 m입니다.
  - X8 모델과의 차이는 63 % 도달 기준 0.02 s 안입니다. 체인이 같고 자세 응답 차이는 속도 응답에 거의 드러나지 않기 때문입니다.
  - 참고로 X8 측정은 0 → 3 m/s의 63 % 도달 0.57 s, 5 m/s 정지 거리 3.76 m입니다.

## 3. 알려 주시면 바꿀 값

1. 실제 기체의 질량, 프로펠러 크기, 모터·추력. 가장 영향이 큰 것은 충돌 반경을 정하는 프로펠러 끝 반경입니다.
2. 그 기체의 PX4 파라미터: `MC_ROLL_P`, `MC_ROLLRATE_P/I/D`, `MPC_XY_VEL_P_ACC`, `MPC_TILTMAX_AIR`, `CA_ROTOR*`
3. LiDAR 장착 높이, 다리 바닥 높이
4. X500 + PF로 잰 속도 계단 응답. X8 문서 5.2절과 같은 형식이면, 지금 X8 체인을 쓰는 1.3절 값을 맞춰 바꿉니다.
